
# MiniOS-Sim

An Operating System Simulator developed in C11 for the CEN 302 Operating Systems course.

## Project Overview

MiniOS-Sim aims to simulate fundamental operating system mechanisms:

- Module A: CPU Scheduling
- Module B: Concurrency and Synchronization
- Module C: Deadlock Management
- Module D: Memory Management
- Capstone Project

## Development Environment

- Ubuntu 24.04 (WSL2)
- C11
- GCC
- GNU Make
- POSIX Threads
- Visual Studio Code

## Build

```bash
make
```

## Run

```bash
./minios sched
```

## Clean

```bash
make clean
```
